# Explainer enplan. (Remotion)

Video vertical 1080x1920, 30 fps, 20 s, sin audio.

## Uso
1. `npm install`
2. Vista previa editable: `npm run studio`
3. Renderizar MP4: `npm run render` (sale en `output/enplan_explainer.mp4`)

Textos: `src/textos.ts`. Colores y tiempos: `src/marca.ts`. Iconos: `public/icons`. Logo: `public/logo`.
