# Video explainer enplan. para negocios

Video vertical 1080x1920, 30 fps, 30 s, sin audio. Hecho con Remotion.

## Comandos
1. Instalar: `npm install`
2. Renderizar el MP4: `npm run render` (sale en `output/enplan-negocios.mp4`)
3. Vista previa para editar: `npm run studio`

## Dónde editar
1. Textos: `src/textos.ts`
2. Tiempos de cada escena: `src/Video.tsx`
3. Colores, tipografía y zona segura: `src/marca.tsx`
4. Diseño de cada escena: `src/scenes/Escenas.tsx`
5. Logo e iconos: `public/logo` y `public/icons`

Ver también `textos.md` y `PENDIENTES.md`.
